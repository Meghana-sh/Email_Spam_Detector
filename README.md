📧 Email Spam Detector

A machine learning–based system that classifies emails as Spam or Not Spam (Ham) using text preprocessing and classification algorithms. This project helps improve email security by identifying unwanted or malicious messages automatically.

🚀 Features

Preprocessing of raw email text (cleaning, tokenization, stopword removal)

Feature extraction using TF-IDF / Bag-of-Words

Machine learning models for spam classification

Training & validation loss/accuracy analysis

Performance evaluation and confusion matrix

Easy-to-run notebook in Google Colab

🛠️ Technologies Used

Python

Scikit-learn

Pandas, NumPy

Matplotlib / Seaborn

Google Colab
